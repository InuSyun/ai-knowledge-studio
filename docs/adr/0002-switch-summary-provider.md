# ADR-0002 要約処理のProviderを切り替える

## 背景

ローカルでは実際のLLMで要約できることを確認したい。
公開デモでは、実LLMの利用料をかけずに画面の操作を試せるようにしたい。

## 決定

- 公開デモでは Mock Provider に固定し、デモ用の結果を返す。
- ローカルで実LLMを試すときは Ollama Provider を使う。

## 理由

どちらのProviderを使っても、画面は同じ `POST /api/v1/summaries`
に文章とモードを送る。Providerを切り替えても、画面の送信処理を
変更する必要がない。

## 手間が増える点

Mockと実LLMの両方で、APIが仕様どおりの形式で結果を返すことを確認する。
